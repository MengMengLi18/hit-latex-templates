# 默认版式参数

本文件记录 `hit-proposal.sty` 中的实际设置，便于后续维护；不是学校最新格式规范的声明。

| 项目 | 默认设置 |
| --- | --- |
| 纸张 | 595.35 × 842 bp，A4 舍入尺寸 |
| 四边距 | 70.9 bp，约 25 mm |
| 页眉 | 左侧“哈尔滨工业大学”，右侧报告名称；10.5 bp 宋体，0.75 bp 单实线；封面无页眉 |
| 页脚 | 默认居中显示 10.5 bp 页码；封面不显示；目录用罗马数字，正文从 1 开始 |
| 正文字号 | 12 bp |
| 正文基线距 | 18.72 bp |
| 首行缩进 | 24 bp，约两个汉字 |
| 段前、段后 | 0 |
| 一级标题 | 黑体类字形，15 bp；段前后各 7.8 bp |
| 二级标题 | 黑体类字形，14 bp；编号 12 bp；段前后各 7.8 bp |
| 三级标题 | 黑体类字形，12 bp；独立段落 |
| 四级标题 | 黑体类字形，12 bp；24.18 bp 基线距；独立段落 |
| 目录 | 四级，12 bp，分级缩进和点线页码 |
| 封面校徽 | 官方黑色校徽，裁去白边后宽 32 mm，水平居中 |
| 封面校名 | 官方校名字样，裁去白边后宽 92 mm，水平居中 |
| 封面报告名 | 22 bp，加粗 |
| 封面题目 | 18 bp，加粗，31.2 bp 基线距，居中 |
| 封面信息 | 16 bp，加粗，35 bp 基线距，带下划线 |
| 图表题注 | 10 bp，15.6 bp 基线距，居中 |
| 文献正文引用 | 上标方括号数字，排序并压缩连续编号 |
| 参考文献表 | 12 bp，15.6 bp 基线距；编号及续行均左对齐，无悬挂缩进 |

`bp` 为 1/72 英寸，与 TeX 的 `pt` 不同。

默认的中文正文和标题分别使用 FandolSong、FandolHei；楷体命令使用 FandolKai；西文使用 TeX Gyre Termes。封面校徽和校名使用 `assets/` 中保存的官方图片。替代字体与其他宋体、黑体、楷体的字形和断行可能不同。封面采用固定位置排版，较长的标题及字段需人工检查。

表格示例采用 `booktabs` 三线表；它是通用排版示例，不额外宣称对应某种指定表格规范。
